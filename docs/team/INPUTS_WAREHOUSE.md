# Входные параметры объекта «Склад»

Источник: планёрка 18.09, список от робототехников. Это то, что пользователь вводит на экранах визарда.
Ключи (`key`) — как поля будут называться в коде и в формулах экономистов.

## Фаза 1 — подбор роботов (технические ограничения)

Вводится до подбора. По этим полям работают hard-правила из `rules_v0.json`.

| # | key | Поле | Тип | Единица / варианты |
|---|---|---|---|---|
| 1 | `area_total_m2` | Площадь склада | число | м² |
| 2 | `ceiling_height_m` | Высота потолков в зоне хранения | число | м |
| 3 | `has_work_zones` | Рабочие зоны | да/нет | — |
| 3.1 | `aisle_main_width_mm` | Ширина главных проездов | число | мм |
| 3.2 | `aisle_rack_width_mm` | Ширина рабочих проходов между стеллажами | число | мм |
| 4 | `floor_type` | Тип напольного покрытия | выбор | `industrial_concrete` промышленный бетон / `self_leveling` наливной / `road_or_ground` дорожное или грунтовое |
| 5.1 | `slope_percent` | Преодолеваемый уклон | число | % (напр. 10% на N м) |
| 5.2 | `slope_length_m` | Длина уклона | число | м |
| 5.3 | `obstacle_mm` | Препятствие | число | мм (до 20 мм — полиуретан, до 50 мм — шина) |
| 6 | `rack_type` | Тип стеллажной системы | выбор (мульти) | `block` горизонтальный/штабельный · `frontal` вертикальный фронтальный · `shelf` полочные · `deep` глубинные · `flow` поточное хранение · `cantilever` консольные · `mezzanine` мезонины |
| 7 | `cargo_type` | Тип груза | выбор | `long` длинномерные · `euro_pallet` европоддон · `custom` нестандартные |
| 7.1 | `cargo_max_length_mm` | Макс. длина (для длинномерных) | число | мм |
| 7.2 | `cargo_dims_mm` | Габариты Д×Ш×В (для нестандартных) | 3 числа | мм |
| 8 | `temp_min_c`, `temp_max_c` | Рабочая температура | 2 числа | °C |
| 9 | `ip_rating` | Требуемая степень защиты IP | выбор | IP20 … IP67 |
| 10 | `budget_rub` | Планируемый бюджет на роботизацию | число | ₽ — **не фильтр при подборе**, помечать «превышает бюджет» после расчёта |

Примечание по мезонинам: там мобильные роботы не проходят — только робособака (до 5 кг на манипуляторе, 15 кг на спине) или гуманоид. Это правило подбора, не поле.

## Фаза 2 — экономический расчёт

Вводится после того, как пользователь выбрал робота. По этим полям считают экономисты.

### A–C. Зона и здание

| key | Поле | Единица |
|---|---|---|
| `area_active_m2` | Площадь активной (роботизируемой) зоны | м² |
| `floors` | Количество этажей | шт |
| `floor_flatness` | Отклонение пола | DIN 18202 / DIN 15185 (класс) |

### D. Режим работы

`work_mode`: `continuous` беспрерывный / `single_shift` односменный / `seasonal` сезонный. Из режима **автоматически** подставляются (пользователь может поправить):

| key | Поле | Единица |
|---|---|---|
| `working_days_per_year` | Рабочих дней в году | дн |
| `shift_hours` | Продолжительность смены | ч |
| `peak_load_factor` | Пиковый коэффициент нагрузки | коэф. |
| `shifts_per_day` | Количество рабочих смен в сутки | шт |

### E. Хранение и грузы

| key | Поле | Единица |
|---|---|---|
| `pallet_weight_kg` | Средняя масса грузовой единицы (паллет) | кг |
| `sku_weight_kg` | Средняя масса штучной единицы (SKU) | кг |
| `sku_dims_mm` | Средние габариты штучной единицы Д×Ш×В | мм |
| `pallet_places` | Кол-во паллетомест | шт |
| `pallet_dims_mm` | Средние габариты паллеты Д×Ш×В | мм |
| `nonstandard_share` | Доля негабаритных/нестандартных грузов | % |

### F. Операции

| key | Поле | Единица |
|---|---|---|
| `inbound_pallets_per_day` | Объём приёмки | поддонов/сутки |
| `outbound_pallets_per_day` | Объём отгрузки | поддонов/сутки |
| `pick_lines_per_day` | Объём отбора | строк/сутки |
| `pick_units_per_day` | Объём отбора | штук/сутки (≈1,5 шт на строку) |
| `piece_pick_share` | Доля мелкоштучного отбора (piece-pick) | % |
| `sku_count` | Количество активных SKU | шт |
| `sku_a_class_share` | Доля SKU с быстрым оборотом (A-класс) | % |

### G. Персонал

| key | Поле | Единица |
|---|---|---|
| `staff_total` | Общая численность | чел |
| `staff_pickers` | Отборщики (комплектовщики) | чел |
| `staff_forklift_ops` | Операторы погрузчиков | чел |
| `staff_packers` | Операторы упаковочной линии | чел |
| `salary_picker_month` | Средняя зп отборщика | ₽/мес |
| `salary_forklift_month` | Средняя зп оператора погрузчика | ₽/мес |
| `payroll_tax_rate` | Страховые взносы | % (по умолчанию 30,2) |
| `picker_lines_per_hour` | Средняя выработка отборщика | строк/ч |
| `time_loss_factor` | Коэффициент потерь рабочего времени (отпуск, болезнь, текучесть) | коэф. |

### H. Маршруты и планировка

| key | Поле | Единица |
|---|---|---|
| `route_length_per_line_m` | Средняя длина маршрута отборщика на 1 строку | м |
| `conveyor_length_m` | Протяжённость конвейерной/транспортной системы | м |

### I–K. Инфраструктура

| key | Поле | Единица |
|---|---|---|
| `power_available_kw` | Мощность электроснабжения (доступная) | кВт |
| `has_wms` | Наличие WMS | да/нет — **обязательное поле** |
| `has_erp` | Наличие ERP / 1С | да/нет |
| `replaced_equipment_cost_rub` | Затраты на заменяемое оборудование | ₽ |

## Что ещё нужно от команды по этому списку

- **Робототехники:** для каждого поля фазы 1 — min / max / значение по умолчанию / подсказка «где взять» (это пойдёт в слайдеры). И какие из полей фазы 2 (E, F, H) участвуют в расчёте количества роботов.
- **Экономисты:** какие поля фазы 2 входят в формулы, а какие — только справочно. См. `TZ_ECONOMISTS.md`.
